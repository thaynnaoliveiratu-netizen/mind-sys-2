# mind sys
O Mind Sys é um aplicativo desenvolvido para ajudar pessoas com TDAH ou com dificuldades de memória e esquecimento a organizar melhor sua rotina e realizar suas atividades diárias.

O aplicativo oferece ferramentas como lembretes, alarmes, lista de tarefas, calendário e anotações, ajudando os usuários a lembrar de compromissos, horários, atividades e tarefas importantes.

Seu principal objetivo é promover mais autonomia, organização e praticidade no dia a dia, proporcionando uma experiência simples, acessível e fácil de utilizar.
